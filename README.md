# Учёт книг в библиотеке

Небольшое настольное приложение на Python и PyQt6 для работы с библиотечным каталогом.

## Что умеет программа

- добавлять, изменять и удалять книги;
- искать книги по названию, автору, жанру, ISBN и году;
- фильтровать книги по статусу;
- отмечать выдачу книги читателю и её возврат;
- показывать общее количество книг, доступные и выданные книги;
- сохранять каталог в JSON;
- записывать время входа и выхода в `report.txt`.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Для Windows:

```bash
.venv\Scripts\activate
```

Установка библиотеки и запуск:

```bash
python -m pip install -r requirements.txt
python main.py
```

## Файлы проекта

- `main.py` — запуск программы и оформление окна;
- `models.py` — классы `Entity` и `Book`;
- `collection.py` — список книг, поиск и работа с JSON;
- `widgets.py` — карточки со статистикой;
- `windows.py` — окна и элементы интерфейса;
- `report.py` — запись времени работы;
- `data/books.json` — начальный список книг.

## Требования задания

- интерфейс сделан с помощью PyQt6;
- есть абстрактный класс `Entity` и класс `Book`, который от него наследуется;
- у классов есть специальные методы;
- у полей книги есть свойства с геттерами и сеттерами;
- для хранения книг используется собственный класс `LibraryCollection`;
- при закрытии программы каталог сохраняется, а время работы записывается в `report.txt`.

```bash
git init
git add .
git commit -m "Добавлено приложение для учёта книг"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/library-manager.git
git push -u origin main
```

В последней команде замените `ВАШ_ЛОГИН` на свой логин GitHub.

Перед сдачей проверьте добавление, редактирование, удаление, поиск, выдачу и возврат книг. Также проверьте, что после перезапуска данные остаются на месте.
